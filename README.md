# E-Commerce Backend System
Backend system for an e-commerce platform supporting user authentication, product management, cart, and order processing.

## Features
- User authentication (JWT)
- Product management
- Shopping cart
- Order management

- ## Tech Stack
- Node.js, Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication

- ## API Endpoints
- GET /products
- POST /auth/login
- POST /orders
- GET /cart

- ## How to Run

1. Clone the repository
2. Install dependencies
   ```bash
   npm install
   npm run dev
